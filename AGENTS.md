# Codebase Rules

## Question and Answer Formatting Rule
Whenever you generate questions or answers, preserve the formatting exactly as written by displaying the content inside an HTML <pre> tag (or render it as preformatted text). Do not modify spacing, indentation, line breaks, tabs, code blocks, bullet alignment, or special characters. The output should appear exactly as authored, with all formatting intact. This rule applies to all types of content, including MCQs, subjective questions, coding questions, programming answers, SQL queries, Linux commands, YAML files, JSON, XML, shell scripts, configuration files, logs, and explanations where formatting is important. Never automatically wrap or reformat the text—always preserve the original layout exactly.
